# PaneCue v0.1 Support Matrix

Status: **v0.1 local qualification complete on macOS 26 Apple Silicon**

“Target” means the combination is part of the release contract. It becomes
“Verified” only after the named acceptance matrix passes on a packaged,
signed beta build.

## Platforms

| Area | Status | Contract |
|---|---|---|
| macOS 14 | Deferred | Remains a source/build compatibility target, but is not qualified or supported by v0.1 |
| macOS 15 | Deferred | Requires a separate packaged-app qualification run before support is claimed |
| macOS 26 | Verified | v0.1 qualified on macOS 26.5.2 |
| Apple Silicon | Verified | v0.1 qualified on Apple M3 |
| Intel | Deferred | No binary or support claim until separately built and qualified |
| Built-in display | Verified | Full v0.1 smoke matrix passed |
| One external display | Verified | Explicit placement, Apply, Undo, disconnect handling, and Rollback passed with Sidecar |
| More than two displays | Experimental | No release guarantee |
| Current Space | Target | PaneCue operates only in the current Space |
| Move between Spaces | Not supported | PaneCue does not move windows between Spaces |
| Stage Manager | Limited | No correctness guarantee in first beta |

## Window behavior

| Window state | Status | Behavior |
|---|---|---|
| Normal resizable window | Supported target | Preview, Apply, and Undo |
| Non-resizable or system window | Limited | Skip and explain |
| Full-screen window | Limited | Never leave full-screen without confirmation |
| Minimized window | Limited | Keep minimized, skip it with a readable reason, and preserve Rollback for targets that moved |
| Window closed after Preview | Supported failure path | Revalidate before Apply |
| Unsaved document | Protected | PaneCue never closes or terminates the app |
| Multiple matching windows | Supported failure path | User chooses from candidates |

## Display limitations

- PaneCue uses the visible work area and avoids the Dock and menu bar.
- An external display target never silently falls back to the main display.
- Display disconnection between Preview and Apply skips only the external
  target with a readable reason and preserves Rollback for targets that moved.
- Different scaling, Dock positions, and menu-bar ownership must be covered by
  the display matrix.

## Qualification matrix

Each supported macOS version must pass:

1. install and Accessibility onboarding;
2. inventory of one and multiple windows per reference app;
3. Preview fidelity;
4. move and resize;
5. three-window Apply;
6. Undo;
7. app relaunch after a saved Cue;
8. full-screen and minimized failure behavior;
9. one external display where applicable;
10. offline execution with network disabled.

The v0.1 supported platform scope is macOS 26 on Apple Silicon. Its packaged
matrix is recorded in `v0.1-smoke-2026-07-26.md`. macOS 14, macOS 15, and Intel
remain outside the v0.1 support claim until each receives a separate full
qualification run. No application can be labeled “Supported” in public
documentation until its matrix passes on a supported platform and no P0/P1
issue remains.
