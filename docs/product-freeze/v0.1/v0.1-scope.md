# PaneCue v0.1 Scope

Status: **Locally qualified on macOS 26 Apple Silicon**

Release target: **0.1.0 source milestone; public binary distribution deferred**

This document defines the release contract. “Included” does not mean every
item is complete today; it means the item must be implemented, tested, and
documented before the public beta can ship.

## Included

| Capability | Release requirement | Current state |
|---|---|---|
| Text command | Primary entry point in Russian and English | Implemented in Arrange |
| PaneCue Mini v2 | Default local parser | Implemented and bundled |
| Plan for 1–8 windows | Parse and display one to eight targets | Implemented |
| Preview before Apply | No launch or movement before approval | Implemented as the primary Arrange flow |
| Mouse editing | Move and resize plan windows on the 24 × 16 grid | Implemented |
| Contextual clarification | Follow-ups edit the visible plan | Implemented |
| Apply | Explicit user action only | Implemented with immediate target revalidation and per-window outcomes |
| Undo/Restore | Adjacent to the Apply result | Implemented, including Rollback after partial Apply |
| App or role matching | Specific app, browser, IDE, notes, meeting, documentation | Implemented |
| Saved Cues | Save and reuse layouts | Implemented in Cues |
| Global shortcut | Open or start the primary Arrange flow | Implemented; opens Arrange in the stable profile |
| Launch application | Only after Preview and explicit Apply | Implemented and gated by Apply |
| Open URL | Only after Preview and explicit Apply | Implemented and gated by Apply |
| Import/Export Cue | Portable user-initiated Cue file | Implemented with a versioned, validated JSON archive |
| One external display | Limited support with explicit placement | Implemented and qualified with Sidecar |
| Offline speech | Optional after successful text onboarding | Implemented, not part of first-run requirements |
| Diagnostics export | Local preview followed by manual export | Implemented with a sanitized JSON preview |
| Reset Personalization | Clear corrections and user learning locally | Implemented; Cues, permissions, and credentials are preserved |

## Experimental and off by default

These capabilities may exist behind an explicit experimental switch, but
cannot appear in onboarding or block the public beta:

- Suggestions Beta, currently named Auto Mode;
- Cloud Voice and BYOK;
- advanced scenario conditions;
- layouts involving more than one external display.

Experimental features must clearly state:

- the additional permission or network use;
- what data leaves the Mac;
- how to disable the feature;
- how to remove stored credentials or data.

## Deferred beyond public beta

- Chrome Picture in Picture and video-tab control;
- FaceTime or ScreenCaptureKit video preview;
- vision-based browser cropping;
- Qwen, FunctionGemma, and Ollama experiments;
- automatic Apply without confirmation;
- Spaces automation;
- accounts, sync, teams, or centralized management;
- macOS 14 and macOS 15 support until packaged qualification hardware or
  virtual machines are available;
- Intel distribution without separate qualification;
- Mac App Store distribution;
- payments or subscriptions.

## Required separation from the current prototype

Before a public beta build is produced:

1. The main build must not contain active browser-video or call-capture entry
   points.
2. Screen Recording and Apple Events usage descriptions must be removed from
   the main build unless a separate experimental build includes them.
3. Cloud Voice/BYOK and alternative local-model experiments must be hidden
   behind an experimental feature gate that is off by default.
4. The first-run text flow must not ask for an API key, microphone, speech
   recognition, or screen recording.
5. The main navigation must be reduced to Arrange, Cues, and Settings.

## Scope-change rule

A new capability enters v0.1 only when it:

1. is required by the frozen happy path;
2. removes a P0 or P1 risk;
3. is required for installation or updating; and
4. adds no new permission or external service.

Everything else is assigned to v0.2+.

The local v0.1 release gate is complete for macOS 26 on Apple Silicon. Public
binary distribution remains a separate deferred gate requiring Developer ID
signing and notarization.

## Release gate

The scope is complete only when every Included item is either:

- implemented and covered by an acceptance test; or
- explicitly removed from this document through a recorded Product Freeze
  decision.
