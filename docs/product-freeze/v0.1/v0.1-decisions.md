## Data and privacy contract

By default:

- commands and plans are processed locally;
- no screenshot is created;
- window titles are not written to logs;
- document paths and URLs are not persisted as diagnostics;
- no remote telemetry is sent;
- corrections and Cues remain on the Mac;
- Reset Personalization removes local corrections and learning;
- diagnostics are previewed and exported only through an explicit user action.

Experimental Cloud Voice must separately disclose:

- the exact command/audio data transmitted;
- the processor and endpoint receiving it;
- when network access begins and ends;
- how the API key and remote access are removed;
- offline and error behavior.

No experimental privacy contract can weaken the main offline build.

## Success metrics

### Product

- At least 80% of beta users reach a first applied layout within three
  minutes.
- At least 70% of Previews are applied without complete recreation.
- At least 30% of closed-beta users return after one week.
- Returning users apply a median of at least five layouts per week.
- Undo succeeds for at least 99% of windows PaneCue successfully moved and
  that remain available.
- PaneCue closes zero third-party windows.

### Technical

- Zero open P0 defects.
- Zero known data-loss defects.
- Crash-free sessions at or above 99.5%.
- Apply success at or above 95% across reference apps.
- Idle CPU below 1%.
- Target idle memory below 100 MB by 1.0.
- The core offline flow performs zero network requests.

### Local parser

Measured separately for Russian and English:

- intent accuracy at or above 90% on a frozen human-authored corpus;
- dangerous false-positive rate below 0.5%;
- No Action evaluated as a separate class;
- synthetic training data is never the only evidence of quality.

## Remaining implementation conflicts

This remains the blocker between the prototype and a locally qualified v0.1
candidate:

1. The manual macOS smoke cases and packaged support-matrix qualification are
   not complete.

Apple Developer Program enrollment, Developer ID signing, and notarization
are deferred. They do not block local qualification or source development,
but a downloadable public beta must not be published until they are complete.

Resolved on 2026-07-26:

- the first recorded macOS 26 Apple Silicon smoke pass now covers stable
  launch, explicit Russian two- and three-window layouts, complete
  three-window Apply and Undo, and partial Apply with Rollback;
- natural layout descriptions no longer require an action verb, common
  Russian plain size language is preserved, and regression tests freeze both
  behaviors;
- a compact third window now receives one quarter of the secondary column's
  height instead of being equal to its supporting window, while the secondary
  column remains wide enough for the macOS Notes window;
- a saved Cue now has recorded macOS 26 evidence for process relaunch, Apply,
  Undo, native export, native import, unique-name adjustment, and persistence;
- packaged macOS 26 evidence now confirms that Preview does not launch a
  closed application, Apply does, a target closed after Preview is reported
  without being relaunched when its Cue disables launch, and multiple matching
  windows are skipped with a readable candidate count instead of being chosen
  silently;
- packaged macOS 26 evidence now confirms on one physical display that
  full-screen and minimized targets remain untouched, receive readable skipped
  statuses, and do not prevent an available target from moving and rolling
  back;
- a clean Accessibility reset now has packaged macOS 26 evidence covering the
  pre-grant Preview, blocked Apply, System Settings approval, status refresh,
  exact two-window Apply, and Undo;
- Local only mode now has a recorded packaged Preview → Apply → Undo pass with
  exact frames and continuous process-level socket monitoring; PaneCue opened
  no network socket during the flow;
- natural size markers now bind by their full text range and prefer the
  following target on an equal-distance tie, preventing a phrase such as a
  large browser with a small Terminal from reordering the three-window plan;
- three-window plans with Notes as the supporting app now reserve a 44% column
  and use an 80/20 secondary split, while frame application uses an edge-safe
  position/size sequence and preserves truthful partial-result reporting when
  an application still enforces its own constraint;
- a fresh main window with no saved frame now centers on the primary display,
  while subsequent launches continue to restore the position chosen by the
  user;
- dashboard actions that reach AppKit or `AppDelegate` retain main-actor
  isolation, preventing the Swift concurrency runtime trap found during live
  Apply;
- Apple Developer Program enrollment was explicitly deferred; the current
  milestone is a locally qualified v0.1 candidate rather than a public binary;
- the release pipeline now supports hardened-runtime signing, a versioned DMG,
  Apple notarization, ticket stapling, artifact validation, and a local ad-hoc
  packaging mode that cannot be mistaken for a public release;
- the stable app now opens directly in `Arrange / Cues / Settings`;
- the stable first run requests no permission and exposes optional offline
  speech only after a successful text Apply;
- cloud voice, BYOK, Suggestions Beta, browser video, and call capture have no
  active entry points in the stable profile;
- Screen Recording and Apple Events usage descriptions exist only in the
  separately identified `PaneCue Experimental.app` bundle;
- Cues can be imported and exported through a validated, versioned archive;
- diagnostics are sanitized, previewed locally, and manually exported;
- Reset Personalization removes saved command corrections and ephemeral
  suggestion learning without deleting Cues or credentials;
- Apply now refreshes target windows before mutation, snapshots every
  changeable target before the first move, reports a status for every window,
  and places Undo or partial Rollback beside the result;
- runtime logs contain only static event categories; a source-level regression
  test rejects public interpolation and sensitive window or command fields;
- the automated v0.1 acceptance gate covers both command languages, Preview
  editing, Apply preflight, partial Rollback, offline packaging, and Cue
  round-trips; system permission and real-window smoke cases are documented
  separately.
