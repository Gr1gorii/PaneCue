# PaneCue v0.1 Product Brief

Status: **Frozen**

Freeze date: **2026-07-25**

## Target user

PaneCue v0.1 is for developers and knowledge workers on Apple Silicon Macs
who keep roughly 8–20 windows open, change working context frequently, and
do not want to configure a permanent tiling manager, Spaces automation, or a
large library of presets.

It is not positioned for:

- users who want continuous automatic tiling;
- managed enterprise deployments;
- complex Spaces or multi-monitor automation;
- Windows or Linux users;
- users who only need standard half- and quarter-screen snapping.

## Problem

The user already knows how the desktop should look for the next task, but
still spends time moving windows manually or preparing layouts in advance.

## Job to be Done

> When I switch to another task, I want to describe the workspace I need in
> one phrase, review and adjust the result, and apply it safely, so I do not
> have to arrange every window by hand or risk losing my current layout.

## Positioning

Russian hero statement:

> Расставьте текущие окна одной фразой. Проверьте план, примените его и
> отмените в любой момент.

English hero statement:

> Describe the desk you need. Review the plan. Apply it. Undo anytime.

Short line:

> Intent, not coordinates.

PaneCue is:

- an intent-to-layout tool;
- an offline-first semantic command parser;
- a preview-first workflow;
- a deterministic executor of explicit window operations;
- a tool for situational layouts as well as saved Cues.

PaneCue is not:

- a permanent tiling window manager;
- a replacement for macOS Spaces or Stage Manager;
- an autonomous agent that changes the desktop without approval;
- a document-content analysis tool;
- a browser-video utility;
- “the first AI window manager.”

## Product promises

1. **Preview before movement.** No window moves before Apply, and Preview
   shows every window PaneCue intends to affect.
2. **Editable plan.** The user can resize, reposition, add, remove, or clarify
   the visible plan before applying it.
3. **Reversible result.** Undo is available next to a successful result and
   restores every window PaneCue successfully moved when that window remains
   available.
4. **Offline core.** Text command, Preview, Apply, and Undo work without the
   network and require only Accessibility permission.
5. **Narrow authority.** PaneCue moves only explicitly listed windows. It
   never closes or terminates another application and never applies a layout
   automatically in v0.1.

## Prohibited claims

Marketing, onboarding, and release notes must not claim that PaneCue:

- understands arbitrary desktop or document content;
- is a general-purpose AI agent;
- supports every macOS application;
- provides complete Spaces or multi-display automation;
- works fully autonomously;
- requires cloud AI for its core flow;
- is a browser-video or call-capture product;
- is the first AI window manager.

## Definition of the product

PaneCue v0.1 is a free, offline-first application for Apple Silicon Macs.
Users describe a layout of their current windows in Russian or English,
review and edit the plan, explicitly apply it, and can undo the result. The
core flow uses Accessibility only and performs no network request.

Chrome video, ScreenCaptureKit call preview, cloud voice, automatic Apply,
Spaces automation, accounts, sync, and team functionality are not part of
the first public release.
