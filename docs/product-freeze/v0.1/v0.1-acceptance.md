# PaneCue v0.1 Acceptance Gate

Status: **Automated gate implemented; macOS 26 core smoke passed; full matrix pending**

Run the complete automated gate from the repository root:

```sh
./scripts/run_v01_acceptance.sh
```

The command runs the Swift acceptance and regression suites, packages the
stable application, verifies its signature and release identity, confirms
that experimental permission descriptions are absent, and checks the bundled
offline parser against its release size budget.

## Manual macOS smoke procedure

Use [the support matrix](v0.1-support-matrix.md) and record the macOS version,
Mac model, display configuration, applications, pass/fail result, and issue
link for every failure. Do not add window titles, commands, URLs, or document
paths to the record.

For every layout smoke case, record the expected normalized position and size
from Preview, then verify the applied X, Y, width, and height for every target.
An outcome label such as `Moved` is not sufficient when the Preview geometry
itself is wrong.

The public beta is not closed until all remaining system smoke cases pass on
the packaged `PaneCue.app` and the result is recorded.
