## Issues found and resolved during the pass

- Natural layout descriptions without an action verb previously fell through
  to a generic two-window preset.
- Russian plain size language did not select the requested dominant window.
- Dashboard action closures lost main-actor isolation and could trigger a
  Swift concurrency runtime trap during Apply.

Regression tests were added for the command cases, and all dashboard actions
that reach AppKit or `AppDelegate` are now explicitly main-actor isolated.

## Qualification state

This pass qualifies the core local Arrange → Preview → Apply → Undo journey on
one macOS 26 Apple Silicon configuration. It does not close the full v0.1
support matrix; the remaining manual cases above and the other target macOS
versions still require recorded runs.
