# PaneCue v0.2 Product Brief

Status: **Frozen**

Freeze date: **2026-07-28**

Release theme:

> **Fast, local, explicit, recoverable.**

## Target user

PaneCue v0.2 is for developers and knowledge workers on Apple Silicon Macs
who frequently switch tasks, know which applications they need, and want to
arrange their current windows without opening or configuring a permanent
tiling manager.

It is not positioned for:

- users who want continuous automatic tiling or unattended Apply;
- managed enterprise deployments;
- Spaces or calendar automation;
- teams that need account sync;
- Intel, Windows, or Linux users;
- users who need Chrome video extraction or call capture.

## Problem

PaneCue v0.1 can safely build and apply a layout, but the user must first open
the main application. It also resolves ambiguous windows too late and keeps
Undo state only in memory. A public beta needs a faster entry point, an
explicit choice before ambiguous targets can be applied, and recovery after
PaneCue itself restarts.

## Job to Be Done

> When I switch to another task, I want to summon PaneCue from the application
> I am using, describe the workspace I need, resolve any uncertainty, and
> explicitly apply a recoverable plan without depending on the internet.

## Definition of the product

PaneCue v0.2 is the first publicly installable beta for macOS 26 on Apple
Silicon. The user presses `Option-Space`, enters or explicitly records a
Russian or English command, reviews a local Preview, resolves any ambiguous
window, and presses Apply. PaneCue keeps a privacy-safe journal of the last
five Apply transactions and can offer recovery after PaneCue restarts.

Apple Shortcuts and Raycast can open PaneCue or create a Preview through the
`panecue://` URL scheme. No external invocation can apply a layout.

The core arrangement flow works without the internet. The only network
component in the stable application is the update system, which runs manually
or after explicit opt-in.

## Product promises

1. **Fast entry.** `Option-Space` opens Quick Cue over the current application
   without requiring the main window.
2. **Preview before movement.** Text, voice, saved Cues, and external links
   create a Preview. They never apply a layout themselves.
3. **No silent guessing.** If several windows match a required slot, Apply
   remains unavailable until the user chooses.
4. **Explicit authority.** Every Apply requires a visible, direct user action
   inside PaneCue.
5. **Recoverable operations.** Undo is available after Apply, and a
   privacy-safe journal can offer restoration after PaneCue restarts.
6. **Offline core.** Parsing, Preview, selection, Apply, Undo, and recovery do
   not require a network connection.
7. **Narrow data collection.** The journal excludes command text, transcripts,
   window titles, document paths, URLs, and credentials.

## Prohibited claims

Marketing, onboarding, and release notes must not claim that PaneCue v0.2:

- applies layouts automatically;
- understands arbitrary desktop, document, or browser content;
- restores documents or the complete workspace after a Mac reboot;
- supports every macOS application;
- supports macOS 14, macOS 15, or Intel;
- manages Spaces or more than one external display;
- provides cloud voice in the stable build;
- captures Chrome video or calls;
- is a general-purpose autonomous computer agent;
- keeps the core arrangement flow local if update-network behavior is not
  disclosed separately.

## Success criteria

- Quick Cue appears in under 200 ms at P95 while PaneCue is running.
- A normal local text command reaches Preview in under 500 ms at P95.
- Known ambiguous targets are resolved explicitly or produce No Action.
- No frozen no-action case causes a dangerous operation.
- Restore succeeds for at least 99% of still-available, unambiguous windows.
- The core arrangement path opens no network connection.
- A signed, notarized, stapled DMG launches through Gatekeeper on a clean Mac.
