# PaneCue v0.2 Decision Record

Freeze date: **2026-07-28**

Decision states:

- **Decided** — part of the v0.2 release contract.
- **Deferred** — explicitly does not block v0.2.
- **Blocking** — required before a public artifact can ship.

- automatic Apply;

- payments and licensing enforcement;
- Mac App Store distribution.

## Scope-change rule

After this freeze, a v0.2 scope change requires a dated entry in this record
with:

1. the problem and affected release gate;
2. the safety, privacy, permission, network, and schedule impact;
3. the capability removed or deferred to keep the release bounded; and
4. explicit approval before implementation.

No experimental feature may become a stable release blocker.
