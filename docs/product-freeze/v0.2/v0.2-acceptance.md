# PaneCue v0.2 Acceptance Gate

Status: **Frozen; implementation not started**

Qualified platform: **macOS 26 on Apple Silicon**

Public artifact: **Developer ID signed, notarized, and stapled arm64 DMG**

## Release-gate sequence

### G0 — Scope frozen

- [x] Included and Deferred scope are explicit.
- [x] Version is `0.2.0`.
- [x] Support remains macOS 26 on Apple Silicon.
- [x] Public channel is GitHub Releases with a signed and notarized DMG.
- [ ] Apple Developer Program enrollment has started.

### G1 — Stable binary safe

- [ ] Stable and experimental SwiftPM targets are physically separated.
- [ ] Stable `PaneCue` contains no experimental object code.
- [ ] Stable bundle contains no Screen Recording or Apple Events usage text.
- [ ] Stable binary contains no ScreenCaptureKit, OpenAI, Chrome AppleScript,
  or Ollama endpoint.
- [ ] Experimental Chrome cleanup operates only on PaneCue-owned resources.
- [ ] Experimental Ollama cleanup unloads only a model launched by PaneCue.
- [ ] All 85 v0.1 tests pass without weakened assertions.
- [ ] The core arrangement path opens no network connection.

### G2 — New functionality complete

- [ ] Arrange, Quick Cue, PaneCue Links, and Cues use one Arrangement
  Coordinator.
- [ ] Quick Cue opens from any application through `Option-Space`.
- [ ] Text and optional offline voice create an editable Preview.
- [ ] Ambiguous targets require explicit selection.
- [ ] External invocation can create only visible UI or Preview.
- [ ] Apply Journal stores at most five privacy-safe transactions.
- [ ] PaneCue restart recovery requires explicit confirmation.

### G3 — Product quality

- [ ] Quick Cue open latency is below 200 ms at P95.
- [ ] Normal local Preview latency is below 500 ms at P95.
- [ ] One hundred open/close cycles leave no orphan windows or observers.
- [ ] Idle Quick Cue adds less than 1% CPU.
- [ ] Delta-operation accuracy is at least 95%.
- [ ] Pronoun/referent resolution accuracy is at least 90%.
- [ ] Every known ambiguous case is resolved explicitly or requests a choice.
- [ ] Frozen no-action cases produce zero dangerous actions.
- [ ] Restore succeeds for at least 99% of available unambiguous targets.
- [ ] Keyboard and VoiceOver blockers are zero.

### G4 — Apple trust

- [ ] The app is signed with Developer ID Application and a secure timestamp.
- [ ] Hardened Runtime is enabled.
- [ ] `get-task-allow` is absent.
- [ ] The App Sandbox remains disabled as a documented design decision.
- [ ] Notarization returns `Accepted`.
- [ ] The ticket is stapled and validates offline.
- [ ] `syspolicy_check distribution` passes.
- [ ] A quarantined Safari download launches through Gatekeeper on a clean Mac.
- [ ] A standard non-admin user can install and run the app.
- [ ] Accessibility denial, grant, revocation, and signing-identity migration
  are tested.
- [ ] Sparkle RC1 to RC2 update succeeds with signature verification.

### G5 — Public release

- [ ] RC1 is tested by 5–10 external users.
- [ ] RC2 passes seven days without an open P0 or P1.
- [ ] The GA artifact is byte-identical to the final tested RC artifact.
- [ ] DMG, checksum, source tag, install guide, privacy notes, limitations,
  Shortcuts guide, changelog, and support link are published.
- [ ] A `0.2.1` hotfix procedure is ready.

## Automated acceptance

The final release command is:

```sh
./scripts/run_release_acceptance.sh --version 0.2.0
```

It must verify:

- all existing v0.1 regression tests and all new v0.2 tests;
- stable and experimental compilation;
- physical binary separation and permission descriptions;
- release identity and build number;
- local parser size and benchmark thresholds;
- no-action corpus safety;
- URL router validation and fuzz cases;
- Journal schema, atomic writes, corruption handling, and bounded history;
- Quick Cue lifecycle and performance instrumentation;
- signature, entitlements, nested-code signing, and package structure.

Packaging does not replace manual macOS verification.

## Frozen benchmark

The independent human-authored corpus contains at least:

- 200 Russian commands;
- 200 English commands;
- 100 contextual follow-ups;
- 200 no-action, negation, and ambiguous cases;
- contributions from at least five authors.

The release test set is not used to train v0.2.

## Required system smoke matrix

Record the macOS version, Mac model, display configuration, app versions,
expected Preview geometry, actual geometry, pass/fail result, and issue link.
Do not record command text, transcript, window title, document path, or URL.

Required packaged-app cases:

1. Quick Cue from Safari, Finder, Terminal, and VS Code.
2. RU and EN text flow.
3. Optional RU and EN offline speech.
4. Two matching browser windows and keyboard candidate selection.
5. Selected target closes or changes before Apply.
6. Apply, Undo, partial Apply, and Rollback.
7. Crash between Journal write and first/last mutation.
8. Relaunch recovery with complete and partial results.
9. Corrupt and truncated Journal.
10. Sidecar connected and disconnected after Preview.
11. Deep links from Terminal, Safari, Shortcuts, and Raycast.
12. Malformed, oversized, unknown, and repeated deep links.
13. Accessibility denied, granted, and revoked.
14. Offline core with process-level network monitoring.
15. Quarantined clean-machine install and RC1 to RC2 update.

## Release blockers

- any P0 or P1 defect;
- any automatic or externally triggered Apply;
- any silent choice among ambiguous windows;
- any stable-binary experimental code or permission;
- any command, transcript, title, document path, URL, or credential in Journal,
  logs, diagnostics, or telemetry;
- any failed signing, notarization, stapling, Gatekeeper, or update check;
- any unsupported claim for macOS 14, macOS 15, Intel, or more than one external
  display;
- any difference between the final tested RC and the GA artifact.
